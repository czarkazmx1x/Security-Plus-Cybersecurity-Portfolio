# Project 05: Risk Assessment and Ransomware Response

**Status:** 🔴 Not started  
**Focus:** Security+ SY0-701 practical skills

## Business scenario
A fictional 30-person organization uses cloud email and stores customer records but has no formal security risk register or ransomware response plan.

## Goal
Demonstrate these security skills through a controlled, documented exercise, with clear expected versus observed results.

## Planned tools
Markdown or spreadsheet; NIST Cybersecurity Framework

## Implementation checklist
- [ ] Inventory critical assets, data, and business processes
- [ ] Identify at least five plausible threats and vulnerabilities
- [ ] Define a documented likelihood/impact scoring scale
- [ ] Build a risk register and prioritize treatments
- [ ] Map proposed controls to relevant security outcomes
- [ ] Write a ransomware response playbook with roles and escalation
- [ ] Describe backup validation, recovery, and communication activities
- [ ] Draft a one-page executive summary

## Success criteria
Each identified risk has a rationale, owner/role, recommended mitigation, and residual-risk considerations.

## Evidence to add after completion
Asset inventory; risk register; scoring rubric; incident response plan; executive summary
