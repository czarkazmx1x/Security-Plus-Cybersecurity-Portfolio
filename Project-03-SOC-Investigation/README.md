# Project 03: SOC Authentication Investigation

**Status:** 🔴 Not started  
**Focus:** Security+ SY0-701 practical skills

## Business scenario
A fictional security operations team sees multiple failed sign-ins on a lab workstation and must assess whether the activity is suspicious.

## Goal
Demonstrate these security skills through a controlled, documented exercise, with clear expected versus observed results.

## Planned tools
Windows Event Viewer or Linux journal; Wazuh or Splunk (optional)

## Implementation checklist
- [ ] Configure a Windows or Linux lab endpoint and record its logging setup
- [ ] Generate several controlled failed logins to a test account
- [ ] Collect relevant authentication event records
- [ ] Normalize timestamps and construct a short incident timeline
- [ ] Differentiate observed facts from hypotheses
- [ ] If available, configure SIEM ingestion and a detection rule
- [ ] Document the investigation, assessment, and response recommendation
- [ ] Redact usernames, IPs, and secrets as appropriate before publishing

## Success criteria
Findings cite specific observed events and explain why the activity does or does not warrant escalation.

## Evidence to add after completion
Redacted event excerpts; timeline; optional SIEM dashboard; investigation report; detection validation
