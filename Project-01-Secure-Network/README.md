# Project 01: Secure a Small Business Network

**Status:** 🔴 Not started  
**Focus:** Security+ SY0-701 practical skills

## Business scenario
A fictional 20-person company needs separated management, staff, and guest networks. Guest devices must not reach internal business resources.

## Goal
Demonstrate these security skills through a controlled, documented exercise, with clear expected versus observed results.

## Planned tools
Cisco Packet Tracer; network diagram

## Implementation checklist
- [ ] Draw a topology including router, switch, endpoints, and three VLANs
- [ ] Design and record IP subnets for each VLAN
- [ ] Configure VLANs, switch ports, and inter-VLAN routing in Packet Tracer
- [ ] Apply ACLs to block guest-to-internal traffic while allowing permitted services
- [ ] Configure secure device administration where supported
- [ ] Test expected permitted and denied traffic, including negative test cases
- [ ] Save configuration exports, diagrams, results, and a concise report

## Success criteria
A guest workstation cannot access internal management or staff subnets, while explicitly authorized traffic succeeds.

## Evidence to add after completion
Network diagram; sanitized configuration files; screenshots of test outcomes; access-control test matrix
